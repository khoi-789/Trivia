# 🎮 Trivia Master AI

Real-time trivia application featuring speed-based scoring, custom avatar selection, and question import functionality.

## 🚀 Hoạt động chính
- **Đồ họa cực chất**: Hiệu ứng Neon, 2.5D Studio cực đẹp.
- **Real-time**: Chơi cùng bạn bè qua Socket.io.
- **Import câu hỏi**: Host có thể tải mẫu CSV và tải lên danh sách câu hỏi riêng.
- **Tính điểm tốc độ**: Trả lời càng nhanh điểm càng cao!

## 🛠️ Cách cài đặt & Chạy local

### 1. Phía Backend
```bash
cd backend
npm install
node server.js
```

### 2. Phía Frontend
```bash
cd frontend
npm install
npm run dev
```

Mở trình duyệt tại: `http://localhost:5173/`

## 📦 Công nghệ sử dụng
- **Vite (React)**
- **Express (Node.js)**
- **Socket.io**
- **Framer Motion & CSS Animations**
- **Playwright (để test)**
